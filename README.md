# Hiking Video HUD

把两步路 App 导出的 KML 徒步轨迹，渲染成带 **透明 alpha 通道** 的轨迹动画视频，方便二次剪辑叠加。

工作流：**加载 KML → 拖拽编辑 → 生成视频**（所见即所得）

![工作流](https://img.shields.io/badge/PyQt5-GUI-blue) ![输出](https://img.shields.io/badge/视频-MOV%2FPNG%20alpha-success) ![平台](https://img.shields.io/badge/平台-Windows-lightgrey)

## 功能特性

### KML 解析与时间口径
- 解析 `<gx:Track>` 的 `gx:coord` 坐标点和 `<when>` 时间戳
- 提取 `ExtendedData` 元数据：BeginTime / EndTime / PauseTime / Distance / ElevationGain 等
- **时长口径与两步路 UI 一致**：PauseTime 单位为毫秒，运动耗时 = 墙钟 − PauseTime/1000
- `<when>` 时间戳保留真实停顿节奏（标记在停顿段真实停住）

### 轨迹渲染
- 紫色未走 + 红色已走双色路径，线宽可调（2–30px）
- 起终点彩色圆点 + 白色描边
- 关键节点：用户自定义 JSON 录入（名称/经度/纬度），彩色圆点 + 半透明黑底胶囊白字标签
- 字号、节点颜色、节点字号均可调

### 数据面板（WYSIWYG 拖拽编辑）
- 字段可选：当前海拔 / 累计爬升 / 运动耗时 / 已走距离 / 总耗时 / **当前坡度** / **当前配速**
- **当前坡度**：对称窗口（前后各 3 点）海拔差 / 水平距离 × 100%，15 点平滑抑制 GPS 抖动，物理裁剪 ±60%
- **当前配速**：优先用 KML 内置逐点瞬时速度（前后 2 点均值），无速度字段时回退到窗口距离/时间，格式 `17'43"/km`
- 暂停模型：暂停集中在 `pause_center` 位置（GUI 1–99% 可调），运动耗时在暂停段冻结、总耗时持续

### 地图导航面板
- 高德标准地图瓦片（含路名/村庄名地名标注，WGS-84 → GCJ-02 校正）
- 实时位置为中心，绿色方向箭头（静止时圆形）
- 方形 / 圆形两种形状（圆形 alpha 遮罩裁剪）
- 正北朝上 / 运动方向朝上两种模式（后者整图旋转 + 指北针指示真北）
- 缩放级别 3–18，文字图例 4 档（较小/标准/较大/特大）
- 箭头大小 4–80px 可调
- **浮点 idx 插值 + 30fps 高帧率渲染，地图中心与方向随帧连续变化**

### 分段视频
- 分割点点击轨迹添加，右键删除，圆形序号标记
- 每段独立设置时长，durations 驱动模型（改一段不影响其他段时长，总长自动联动）
- 段端点严格命中 cut 物理位置（保证「段结束→分割点」对齐）
- 段内保留真实行进节奏

### 工程化
- 每份 KML + 渲染参数 = 独立 `.kmlproj` 工程文件（JSON 格式）
- 工具栏：新建 / 打开 / 保存 / 另存为 / 最近工程下拉（最近 10 个）
- 启动自动打开上次工程；脏标记（`*`）提示未保存
- 全局 settings.json 仅存窗口级状态（最近工程、视频输出目录、默认画布、上次工程路径）
- KML 失效时提示重选并标记工程未保存

### 视频输出
- MOV 容器 + PNG 编码，保留 alpha 通道便于剪辑叠加
- 输入/输出帧率显式指定，避免剪辑软件用默认 24fps 重读
- 渲染过程支持「⛔ 终止」按钮，半成品自动清理
- 越界预警：轨迹超出画布会提示并一键适配

## 安装

### 依赖
- Python 3.10+
- [ffmpeg](https://ffmpeg.org/)（需加入 PATH，用于视频合成）

### 步骤

```bash
git clone https://github.com/XiaoTYUT/hiking-video-hud.git
cd hiking-video-hud
pip install -r requirements.txt
```

依赖包：
- `numpy` — 数值计算
- `pillow` — 图像渲染
- `PyQt5` — GUI

## 使用

### 准备 KML
从两步路 App 导出 KML 文件（需含 `<gx:Track>` 格式）。KML 文件本身不入仓库，自行准备。

### 启动 GUI

```bash
python app.py
```

首次启动显示空画布，通过工具栏「📁 打开 KML」加载轨迹文件。

### 编辑流程

1. **加载 KML** → 自动适配画布并初始化布局
2. **拖拽编辑** → 在画布上拖动轨迹、数据面板、地图面板调整位置；滚轮缩放各自大小
3. **设置参数** → 右侧 dock 调节画布尺寸、线宽、字号、节点、帧率、时长、地图样式、数据面板字段
4. **关键节点**（可选）→ JSON 框录入 `[{名称, 经度, 纬度}, ...]`
5. **分段**（可选）→ 勾选分段模式，点「分段设置」添加/删除分割点并设置各段时长
6. **生成视频** → 点「🎬 生成视频」选保存路径，进度条 + 「⛔ 终止」按钮

### 工程文件
- 工程默认存放在 KML 同目录，文件名 `<KML名>.kmlproj`
- 「保存」「另存为…」可自定义位置
- 启动自动恢复上次工程

## 项目结构

```
.
├── app.py           # GUI 主程序（PyQt5 MainWindow + SegmentDialog + RenderWorker）
├── renderer.py      # 数据层 + 视频渲染层（KML 解析 / 投影 / 帧渲染）
├── kml2video.py     # 早期 CLI demo（保留作参考）
├── main.py          # KML 解析最小 demo
├── requirements.txt
├── FEATURES.md      # 详细功能说明
└── README.md
```

运行时会在 `%APPDATA%\KmlPath\` 下生成：
- `settings.json` — 全局窗口级配置
- `tiles/` — 地图瓦片磁盘缓存
- 用户工程文件 `.kmlproj` 存放在 KML 同目录

## 数据与隐私

- **KML 轨迹文件含个人行走路线/时间戳，不入仓库**（见 `.gitignore`）
- 代码中无硬编码个人路径，仅通过 `%APPDATA%` 环境变量访问运行时配置
- 地图瓦片走高德公开 API，离线缓存于本地
